`test_parameter_logic.py` — чистая функция `validate_parameters`:

- `test_frequency_change_to_5_accepted` — обычное изменение 10 → 5 Гц принято;
- `test_zero_frequency_rejected` — 0 отклонено (причина указывает `publish_hz`);
- `test_negative_frequency_rejected` — отрицательная частота отклонена;
- `test_frequency_above_limit_rejected` — 31 Гц отклонено;
- `test_nan_frequency_rejected` — NaN отклонён («finite number»);
- `test_infinity_speed_rejected` — бесконечность отклонена;
- `test_speed_above_limit_rejected` / `test_speed_negative_rejected` —
  скорость вне [0, 1] м/с отклонена;
- `test_turn_below_limit_rejected` — поворот вне [−1, 1] рад/с отклонён;
- `test_boundary_values_accepted` — границы 1/30 Гц, 0/1 м/с, −1/1 рад/с
  приняты;
- `test_default_set_accepted` — значения по умолчанию приняты.

`test_command_logic.py` — команда: без позы → ноль, с позой →
`linear.x = 0.5`, `angular.z = 0.3` (теперь с параметризуемыми
скоростями). `test_copyright` — skipped (нарушений нет). Lint: flake8,
mypy, pep257, xmllint — passed.
